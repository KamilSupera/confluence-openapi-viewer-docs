# OpenAPI (Swagger) Viewer for Confluence

Renders an OpenAPI 2.0 / 3.x definition with Swagger UI inside a Confluence Cloud page. Built on Atlassian Forge, no external servers.

- [Privacy policy](privacy.md)
- [Support](support.md)
- [Publish from CI](ci.md)

## Getting started

1. Install the app from the Atlassian Marketplace.
2. Edit a page, type `/OpenAPI` and insert **OpenAPI (Swagger) Viewer**.
3. Choose **URL** (JSON or YAML, host must allow cross-origin requests) or **Page attachment** (upload the file to the page first).
4. Adjust display options if needed and save.

## Migrating from a Connect-based Swagger macro

Using *Open API (Swagger) Integration*, *Swagger UI for Confluence* or *Open API (Swagger) Editor for Confluence*? Insert OpenAPI (Swagger) Viewer next to the old macro, copy the URL and the same options (names match), remove the old macro.
